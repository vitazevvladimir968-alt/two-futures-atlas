# TWO FUTURES — ДВА БУДУЩИХ

Интерактивный атлас двух возможных сценариев развития человечества на 3D-глобусе.

**Девиз:** «БУДУЩЕЕ НЕ НУЖНО ЖДАТЬ. ЕГО МОЖНО СОЗДАВАТЬ ВМЕСТЕ.»

## Технологии
- React 19, TypeScript, Vite
- TanStack Start / Router
- Three.js, React Three Fiber, Drei
- Zustand, Tailwind CSS

## Локальный запуск
```bash
bun install
bun run dev
```

## Проверки
```bash
bun run test
bun run build
```

## Важное замечание о данных
Показатели и траектории сценариев являются демонстрационной моделью, а не официальными прогнозами или измерениями.

## Состояние переноса
Исходники приложения перенесены из проекта Lovable в этот репозиторий. Для глобуса подключены публичные текстурные ресурсы Three.js (дневная поверхность, ночные огни, рельеф, отражение океанов и облака), поэтому перенос бинарных JPG/PNG из Lovable не требуется. Перед публикацией всё ещё необходимы чистая установка зависимостей, тесты и production-сборка. Не считать репозиторий готовым к публикации до успешной проверки.
